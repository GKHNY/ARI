Konu: Java 11 MCP Framework Geliştirmeleri

Merhaba,

Java 11 için resmi MCP SDK desteği bulunmadığından, tamamen Java ile çalışan hafif bir MCP frameworkü geliştirdim. Bu framework sayesinde LLM tabanlı istemciler (Claude Code, Kilo vb.) Java uygulamalarındaki fonksiyonları standart MCP protokolü üzerinden native tool olarak çağırabiliyor. Başka bir ifadeyle, Java'da yazılmış herhangi bir işlev, modele güvenli ve standart bir arayüz üzerinden kullanılabilir hale getirilebiliyor. Amaç, mevcut Java kodlarının minimum değişiklikle yapay zeka ajanları tarafından kullanılabilmesini sağlamak ve yeni tool geliştirme sürecini mümkün olduğunca kolaylaştırmaktır.

Bu kapsamda yapılan çalışmalar:

Annotation tabanlı bir tool tanımlama yapısı oluşturuldu.
Bir Java metodu yalnızca @McpTool ve parametreleri @McpParam ile işaretlenerek otomatik olarak MCP tool'u haline getirilebiliyor.
Reflection kullanılarak tool'lar otomatik keşfediliyor; manuel registry veya her tool için ayrı wrapper yazılması gerekmiyor.
Metodun parametrelerinden otomatik olarak MCP inputSchema üretiliyor. Primitive tipler ve String parametreler doğrudan destekleniyor.
Tool çağrılarında gelen JSON parametreleri otomatik olarak Java metod parametrelerine dönüştürülüyor.
Metodun dönüş değeri otomatik olarak MCP response formatına çevriliyor.
Böylece geliştiricinin yalnızca iş mantığını içeren normal Java metodunu yazması yeterli oluyor.

Örnek olarak aşağıdaki metod doğrudan MCP tool'u olarak kullanılabiliyor:

@McpTool(
    name = "add_numbers",
    description = "Adds two numbers"
)
public int addNumbers(
        @McpParam(name = "a") int a,
        @McpParam(name = "b") int b) {

    return a + b;
}

Benzer şekilde herhangi bir mevcut servis metodu da aynı yaklaşımla dışarıya açılabiliyor. Tool metodunun içerisinde mevcut proje sınıfları, servisler ve kullanılan kütüphaneler normal Java kodu gibi kullanılmaya devam ediyor. Yani geliştiricinin mevcut iş mantığını değiştirmesine gerek kalmıyor.

Ayrıca geliştirilen framework Claude Code CLI üzerinde test edildi. MCP sunucusu başarıyla tanıtıldı ve örnek tool çağrıları (add_numbers vb.) native MCP tool call olarak gerçekleştirildi.

Bir sonraki aşamada POJO giriş/çıkış tiplerinin desteklenmesi, daha gelişmiş tip dönüşümleri ve otomatik schema üretiminin genişletilmesi planlanmaktadır. Böylece mevcut Java projelerine entegrasyon daha da kolay hale gelecektir.
